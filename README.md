# Shiv Kumar | Lead Engineer – GenAI & Agentic AI

Personal portfolio site for **Shiv Kumar**.

Live: `https://ms-kumar.github.io/shivkumar-portfolio/`

Built with [Hugo](https://gohugo.io/) + [HugoBlox Academic CV](https://hugoblox.com/templates/academic-cv).

## Run locally

Requires Hugo Extended `0.162.0`, Go `1.21+`, Node `22` + `pnpm`.

```bash
pnpm install
hugo server -D
```

Open `http://localhost:1313/shivkumar-portfolio/`

Build:

```bash
hugo --gc --minify
```

## Deploy

Push to `main` (or `site1`) — GitHub Actions builds and deploys to Pages. Enable in Settings → Pages → Source: GitHub Actions.
