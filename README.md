# Shiv Kumar | Lead Engineer – GenAI & Agentic AI

Personal portfolio site for **Shiv Kumar**.

Live: `https://ms-kumar.github.io/shivkumar-portfolio/`

Built with [Hugo](https://gohugo.io/) + Wowchemy.

## Run locally

Requires Hugo Extended `0.100.2` and Go `1.18+`.

```bash
hugo server -D
```

Open `http://localhost:1313/shivkumar-portfolio/`

Build:

```bash
hugo --gc --minify
```

## Deploy

Push to `main` — GitHub Actions builds and deploys to Pages. Enable in Settings → Pages → Source: GitHub Actions.
