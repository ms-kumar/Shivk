## Run Locally

Requirements: Hugo Extended `0.162.0`, Go `1.21+`, Node `22`, and `pnpm`.

```bash
pnpm install
hugo server -D
```

Open `http://localhost:1313/shivkumar-portfolio/`.

Production build:

```bash
hugo --gc --minify
```

## Deployment

GitHub Actions builds and deploys the site to GitHub Pages from `main`.
